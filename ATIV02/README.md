# 🏷️ DIAW Login Page 👨‍💻

> [!NOTE]
> Projeto feito na disciplina de Desenvolvimento e Integração de Aplicações Web, utilizando Java e Spring Boot. 

## Descrição do projeto

Esta atividade tem como finalidade praticar a construção de uma API REST para consulta de dados climáticos, seguindo a estrutura típica de um projeto Spring Boot. 

## Objetivo

- Criar uma login pagel com Spring Boot e thymeleaf;
- Praticar conceitos de desenvolvimento back-end e front-end;
- Entender a estrutura mínima de um projeto Java com Maven.

## Tecnologias utilizadas

- Java 25
- Spring Boot 
- Maven
- REST API
- Git/GitHub
- Thymeleaf 

## Pré-requisitos

Antes de rodar o projeto, certifique-se de ter instalado:

- JDK
- Maven 
- Git
- IDE recomendada: IntelliJ IDEA, Eclipse ou VS Code com extensões Java

## Como rodar o projeto

### 1) Clone o repositório

```bash
git clone <url-do-repositorio>
cd DIAW
```

### 2) Acesse a pasta da atividade

```bash
cd ATIV02
```

### 3) Execute a aplicação

Usando Maven:

```bash
mvn spring-boot:run
```

### 4) Acesse a aplicação

A aplicação normalmente fica disponível em:

```text
http://localhost:8080
```
